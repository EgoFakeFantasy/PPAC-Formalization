## 收尾方法的正确使用

ModelTransfer复用同一个现成纯语言调度。任意Project闭句在所有相应Type 0 ZF模型中的证明，可以回传原核Derives nativeZF [] (fo_sentence φ)。ZF／U模型桥适用于任意模型universe，不要求外部良基、标准ω、可数或传递。

单个标准集合宇宙中的构造不提供上述全模型前提。现成ZFC规范扩张所用的背景仍须核对；本批ZF模型桥没有把整套扩张的前提自动弱化。对象层验收要求通过实际背景和语言对应来满足，不能以宿主一致性或一次成功编译替代。
