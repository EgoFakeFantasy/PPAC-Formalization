```text
UniqueFiber(w,n,t) := ∃a (((a∈w) ∧ Bytes(w,n,t,a)) ∧
                          ∀b (Bytes(w,n,t,b) → b=a))

ZF ⊢ Ω(w) → ∀n,t (UniqueFiber(w,n,t) ↔ (ByteList(w,n) ∧ t∈w))
ZF ⊢ Ω(w) → (∃a (a∈w ∧ Bytes(w,n,t,a)) ↔ (ByteList(w,n) ∧ t∈w))
ZF ⊢ Ω(w) → Bytes(w,n,t,a) → ByteList(w,n)
ZF ⊢ Ω(w) → Bytes(w,n,t,a) → Bytes(w,n,t,b) → a=b
ZF ⊢ Ω(w) → ¬ByteList(w,n) → ¬Bytes(w,n,t,a)
```

所有n、t、a、b为内部集合变量。只有独立输入合法性和自然尾部属于精确纤维的定义域；最终ALL2没有长度、完整图、256见证、递归IH或额外执行见证前提。辅助逐步引理明确保留earlier，不把这些引理误记为全部IH已经消去的最终结果。
